Product Reference · Automotive Studio Management

Zeus Auto Detailing

Reference specification for a high-fidelity interactive Next.js, React, and Tailwind CSS web application.

1. Brand and Visual Specification

  • Aesthetic: Dark Luxury / Performance Automotive Studio
  • Palette: Background #09090b, card surfaces #18181b, borders #27272a, Zeus Gold #f59e0b / #fbbf24
  • Status colors: Emerald for Available, Amber for 1 Bay Left, Crimson for Sold Out
  • Typography: Clean sans-serif such as Inter or Geist, with tabular numbers for PHP pricing and timestamps.
  • Central configuration: Use a brandConfig object containing shop name, location, currency, and default bay capacity.

2. Public Studio Home Page — /

  • Header navigation: logo, Services, Packages, Location, Contact, and primary Book an Appointment button.
  • Do not include an Admin Portal button in the public customer navigation.
  • Hero headline: “Tacloban's Premier Automotive Detailing & Vehicle Protection Studio.”
  • Value propositions: Certified Technicians, Multi-Stage Paint Correction, and Graphene Ceramic Coatings.
  • Primary CTA links to /book.

3. Customer Booking Page — /book

Build an interactive five-step guided wizard with visible progress.

  1. Vehicle Category: Selection cards for Sedan, SUV/Crossover, Pickup/Van, and Motorcycle.
  2. Service Package: Service cards with duration pills and PHP prices.
  3. Date and Bay Slots: Calendar picker and 30-minute time slots using two-bay capacity chips: 2 Bays Open, 1 Bay Left — Filling Fast, and Sold Out.
  4. Customer and Vehicle Information: Customer name, mobile number with +63 prefix, email, vehicle make and model, plate or conduction number, and special notes.
  5. Booking Receipt: Reference code such as ZEUS-849201, appointment summary, vehicle details, estimated finish time, and shop address.

4. Staff Admin Login — /admin/login

Create a centered login card with dark styling, Email / Staff ID and Password fields, a submit button, and error-state handling.

5. Studio Admin Portal — /admin/*

Use a protected layout with persistent dark sidebar navigation and mock data for testing.

Bookings

/admin/bookings — Appointment table with status filters: PENDING, CONFIRMED, IN_PROGRESS, COMPLETED, CANCELLED.

Bay Calendar

/admin/calendar — Two-bay daily and monthly calendar with capacity override controls.

Detailers & Commissions

/admin/detailers — Technician roster, job assignments, and earned commission tracking.

Inventory & Consumables

/admin/inventory — Stock list for ceramic coatings, compound bottles, and pads with low-stock alerts.

Sales Analytics

/admin/analytics — Gross Revenue, Bay Utilization %, and Popular Services metrics.

Interaction Requirements

  • Include working tab switching, wizard step transitions, form states, status filters, and mock data so every interaction can be tested.
  • Use responsive, accessible HTML semantics and preserve the dark luxury automotive visual direction.
